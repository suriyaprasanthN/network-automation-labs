Cisco Network Automation – Show Version using Ansible

📌 Project Overview

This project demonstrates Cisco network device automation using Ansible to retrieve the IOS software version and hardware information from Cisco routers and switches.

Using Ansible Playbooks and SSH connectivity, the automation executes the Cisco IOS show version command remotely without manually accessing each network device.

🎯 Project Objectives

Establish SSH connectivity with Cisco routers and switches.

Automate the show version command using Ansible.

Retrieve Cisco IOS version information.

Collect device uptime and hardware details.

Manage multiple Cisco devices from a centralized Ansible control node.
