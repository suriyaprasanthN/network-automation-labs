This project demonstrates how to automate Cisco router and Router configuration backups using Ansible.

Ansible connects to Cisco network devices through SSH and retrieves their running configurations. The configurations are then saved as backup files for future reference and recovery.

🎯 Objectives

Automate Cisco router and switch configuration backups.

Establish SSH connectivity using Ansible.

Retrieve running configurations from network devices.

Save configuration backups in a local directory.

Reduce manual network administration tasks.
